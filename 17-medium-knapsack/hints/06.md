# Complexity — the same work in a different shape

The two rows and hint 2's one row both take `O(items × capacity)` time and
compute the same cells from the same recurrence; the second row costs
`O(capacity)` more memory. Only the loop body differs: one budget at a time in
scalar registers, or four per instruction with no branch.

Traced on `vec.in`, 64 items with capacity 2000:

| `solve` | scalar per item-capacity pair |
|---|---|
| two rows, C, gcc 12 / clang 21 | 0.01 / 0.01 |
| two rows, Rust, the zipped loop, rustc 1.97 | 0.02 |
| two rows, Go, `archsimd`, Go 1.27.1 | 0.02 |
| one row, select, gcc 12 / clang 21 | 0.00 / over 1 |
| one row, conditional store, gcc 12 / clang 21 | over 1 / over 1 |
