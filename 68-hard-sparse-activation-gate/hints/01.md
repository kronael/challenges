# Hint 1

> Spoilers. Open only when stuck, and only one file at a time.

**The compare is not the problem.** Eight `score > threshold` tests fit one
`vpcmpgtd`, and the compiler emits it without being asked — for a loop that
only *counts* the kept scores. Ask what it cannot emit for the loop that
*writes* them.

Counting first and appending second does not help, and neither does any other
packed pass beside the append: `make vec` counts the work the append does per
score, whatever runs next to it.
