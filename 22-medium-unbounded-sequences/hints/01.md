# Hint 1

> Spoilers. Open only when stuck, and only one file at a time.

**Lazy evaluation / corecursion**: define an unbounded stream that produces
values on demand. A generator (`yield` in a `while True:` loop) gives you this
directly — `next(primes())` returns `2` immediately with no precomputation and
no upper bound chosen up front.

**Laziness is observable**: that same first `next(primes())` must return `2`
immediately with no precomputation and no upper bound chosen up front, and
afterwards the same generator must still be able to yield `3, 5, 7, ...`.
