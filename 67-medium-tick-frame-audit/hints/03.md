# Approach — frame by frame, offset by offset

Lay out the class every offset must hold, once:

```c
uint8_t *expect = xcalloc(width, 1); /* PAYLOAD */
for (size_t k = 0; k < separators_len; k++) {
	expect[separators[k]] = SEPARATOR;
}
expect[width - 1] = TERMINATOR;
```

Then walk the stream frame by frame, and inside a frame offset by offset:

```c
for (size_t f = 0; f < frames; f++) {
	const uint8_t *rec = stream + f * width;
	uint32_t mism = 0;
	for (size_t j = 0; j < width; j++) {
		const uint8_t cls = (rec[j] == '|') * SEPARATOR + (rec[j] == '\n') * TERMINATOR;
		mism += cls != expect[j];
	}
	stray += mism;
	clean += mism == 0;
}
```

Every operand of the inner loop is a unit-stride read, a byte's class is two
compares folded into a number, and the check is one more compare summed into a
counter. gcc 12 turns this body into `vpcmpeqb` / `vpand` / `vpandn` /
`vpsubb` over thirty-two bytes at a time, widens the mismatch bytes with
`vpmovzxbw` / `vpmovzxwd` into `vpaddd`, and leaves the horizontal sum and the
remainder tail outside the loop. Whether the frame is clean is decided once per
frame, outside the lanes. `make vec` grades it at 0.06 scalar instructions per
byte on its fixture, whose frames are 96 bytes wide.

## How the class is computed matters to gcc

Measured with the fixture `make vec` traces, `x86-64-v3`, `-O3`, all in the
frame-by-frame loop above unless noted:

| inner loop | gcc 12.2 | clang 21 |
|---|---|---|
| class from compares, as above | vectorized | vectorized |
| class from an `if` / `else if` chain that assigns it | vectorized | vectorized |
| class from a `switch` | scalar | vectorized |
| one flat loop over the stream with `expect[i % width]` | scalar | scalar |
| a cursor `pos` that wraps at `width` | scalar | scalar |

gcc if-converts a branch that computes a value but not a `switch` (`control
flow in loop`); clang turns the small `switch` into selects. The flat loop is
not a way out either: gcc reports `not suitable for gather load` for
`expect[i % width]`.

## Rust and Go

**Rust** (rustc 1.97): `stream.chunks_exact(width)` with each frame's bytes
zipped against `expect`, the class computed as
`u8::from(b == b'|') + 2 * u8::from(b == b'\n')`, vectorizes; `make vec` grades
it at 0.45 scalar instructions per byte. A `for &b in stream` walk with a
`match` on the byte and a wrapping `pos` stays scalar, like the C control.

**Go**: write the thirty-two lanes with `simd/archsimd`. Load a block with
`archsimd.LoadUint8x32Array((*[32]uint8)(rec[j:]))`, compare it against
`BroadcastUint8x32('|')` and `BroadcastUint8x32('\n')` with `Equal`, and turn
each mask into a `uint32` with `ToBits`. If `expect` is kept as two bit masks
per 32-byte block — where separators and the terminator must be — the stray
bytes of a block are the set bits of
`(pipes ^ wantPipes) | (lines ^ wantLines)`, counted with
`bits.OnesCount32`. A frame's last `width % 32` bytes need a scalar tail. One
such version passes `make vec` at about 0.5 scalar instructions per byte.
