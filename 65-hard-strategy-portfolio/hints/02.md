# Hint 2

**Give the two groups a node each, and turn every rule into a price.** Add two
nodes to the `n` strategies: one standing for *activated* and one for *not*. Every
strategy is on one side or the other of the split between those two nodes, and
hint 1's shortfall is a price list over the pairs the split separates:

| the split separates | price |
|---|---|
| the activated node from earner `i` (so `i` is left out) | `pnl[i]` |
| loss-maker `i` from the not-activated node (so `i` is in) | `-pnl[i]` |
| `a` from `b`, for a pair `[a, b]` (so `a` is in and `b` is out) | forbidden |
| anything else | nothing |

A strategy contributing exactly nothing appears in no row: it is free on either
side, which is right, because activating it changes no total.

**"Forbidden" is a price too, and that is the step worth pausing on.** Putting
every strategy on the not-activated side is a valid choice, and it costs exactly
the ceiling. So any split costing *more* than the ceiling can never be the cheapest
one — and a price of `ceiling + 1` on a prerequisite crossing is therefore as good
as a ban. The cheapest split simply never crosses a prerequisite, so it is always a
valid activation set. One mechanism, priced arcs, now carries both the objective
and the constraint; there is no second pass that repairs an invalid answer, and no
separate feasibility check anywhere.

**Read the price list again and notice what it is.** Each row attaches a number to
an *ordered* pair of nodes and charges it only when the split puts the first node
on the activated side and the second on the other. That is a **directed graph with
capacities**, and the sum charged by a split is the capacity of a **cut** between
the two added nodes. The answer is

```
ceiling - (capacity of the cheapest cut between the two added nodes)
```

**This is also where the input's rough edges stop being rough.** A mutual pair
`[a, b]` and `[b, a]` prices both crossings, so no split can put `a` and `b` on
different sides at all: they go together, whichever side that is. A longer loop
does the same thing around the loop, and nothing has to detect or collapse the
loop first — the prices already say it. A self-reference `[a, a]` prices a crossing
from `a` to itself, which no split can realise, so it costs nothing and needs no
special case. A repeated pair prices the same crossing twice, and since the
cheapest split never crosses it, twice is the same as once.

Which leaves one question, and it is the one the challenge is about: what computes
the cheapest cut between two nodes of a capacitated directed graph, and what does
it cost?
