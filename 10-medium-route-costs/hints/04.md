# Complexity

The naive trap (`rotten/main.py`) settles nodes in shortest-path order but finds
the next node to settle by scanning **all** `n` nodes every round — `O(n²)`
overall. Correct on the small cases, it TIMEOUTs at `n = 2·10⁵`. The golden
keeps the frontier in a heap, so the per-round minimum is `O(log n)` and the
whole run is near-linear in the number of edges.
