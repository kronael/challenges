# Sources

Biological context: Bae, Park, and Kim, ["Cas-OFFinder," Bioinformatics
30(10):1473, 2014](https://academic.oup.com/bioinformatics/article/30/10/1473/267560).
Cas-OFFinder accounts for PAM patterns and is not the source of the seed filter
described above.

Level 3:

- Hongyi Xin, John Greth, John Emmons, Gennady Pekhimenko, Carl Kingsford, Can
  Alkan, and Onur Mutlu, ["Shifted Hamming Distance: a fast and accurate
  SIMD-friendly filter to accelerate alignment verification in read
  mapping"](https://doi.org/10.1093/bioinformatics/btu721), Bioinformatics
  31(10):1553, 2015 — mismatches between a read and a reference window as a bit
  vector computed in SIMD lanes and then counted, the shape hints 5 and 6 build.
- Henry S. Warren, Jr., *Hacker's Delight*, 2nd ed., Addison-Wesley, 2012,
  chapter 5, "Counting Bits" — the in-lane popcount by pairs, nibbles, and
  bytes.
- Wojciech Muła, Nathan Kurz, and Daniel Lemire, ["Faster Population Counts
  Using AVX2 Instructions"](https://arxiv.org/abs/1611.07612), The Computer
  Journal 61(1):111, 2018 — the `vpshufb` nibble lookup clang and rustc emit for
  a vectorized popcount.
- [GCC developer options —
  `-fopt-info`](https://gcc.gnu.org/onlinedocs/gcc/Developer-Options.html) and
  [Auto-Vectorization in LLVM](https://llvm.org/docs/Vectorizers.html) — the
  vectorizer reports quoted in hint 5.
