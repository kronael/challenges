# Complexity

The naive trap (`rotten/main.py`) tries every k-mer occurrence as the first
fragment and backtracks over the rest: at each step it tries every unused k-mer
whose prefix matches the current suffix, accepting a branch only after it uses
every occurrence. This exhaustive edge-order search is correct on the small
cases, but exponential on ambiguous prefixes — it TIMEOUTs on the large ones.
