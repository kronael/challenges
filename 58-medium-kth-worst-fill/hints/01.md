# Hint 1

> Spoilers. Open only when stuck, and only one file at a time.

**One rank does not need the whole ranking**: pick any value from the log as a
pivot and split the fills around it. The size of the "worse than the pivot"
side tells you which side rank `k` falls in, and the other side can be thrown
away untouched — you never look at it again.

**Quickselect**: partition, keep only the side that still contains rank `k`,
and repeat on it. The live range shrinks by a constant factor per round on
average, so the expected total work is `n + n/2 + n/4 + … = O(n)` with O(1)
extra space. Loop instead of recursing; the surviving call is in tail
position.
