# Hint 1

> Spoilers. Open only when stuck, and only one file at a time.

**A link is critical exactly when it lies on no loop.** If some closed loop of
links runs through link `i`, then orders that used `i` can go the long way round
instead, nothing falls out of touch, and `i` is not critical. If no loop runs
through `i`, then `i` is the only route between the two sides it joins, and every
pair of venues straddling it falls out of touch.

That reframing matters because it turns `m` separate questions into one question
about the shape of the whole network: which links lie on a loop, and which do not.
The `m` answers are not independent of one another — they are all statements about
the same structure, so paying for each one separately is paying `m` times for the
same information.

Now think about how a loop reveals itself. Walk out from some venue and keep
walking to venues you have not seen before, never stepping onto a venue twice.
Every so often a link will lead to a venue you *have* already seen. What have you
just discovered when that happens, and which links does it tell you about?
