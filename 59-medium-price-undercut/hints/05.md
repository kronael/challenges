# Sources

- USACO Guide, Gold — *Stacks* (the monotonic-stack module): the
  next-smaller/next-greater scan and the amortized argument for it.
- CP-Algorithms — *Minimum stack / minimum queue*: the same
  discard-what-can-never-win invariant, applied to an aggregate instead of a
  per-element query.
- [LeetCode 739 — Daily Temperatures](https://leetcode.com/problems/daily-temperatures/)
  is this problem with the comparison flipped, and
  [LeetCode 496 — Next Greater Element I](https://leetcode.com/problems/next-greater-element-i/)
  is the same scan reporting the value instead of the distance.
- Where the structure goes next, once the per-element version is second nature:
  the stack that answers "next smaller on the left *and* right" for every
  element is the standard tool for maximal-span problems over an array.
