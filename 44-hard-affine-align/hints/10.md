# Sources

[Rosalind — Global Alignment with Scoring Matrix and Affine Gap

## Level 3

- Michael Farrar, [Striped Smith–Waterman speeds database searches six times
  over other SIMD implementations](https://doi.org/10.1093/bioinformatics/btl582),
  Bioinformatics 23(2):156–161 (2007) — the striped layout and the lazy loop
- Andrzej Wozniak, [Using video-oriented instructions to speed up sequence
  comparison](https://doi.org/10.1093/bioinformatics/13.2.145), CABIOS
  13(2):145–150 (1997) — the anti-diagonal layout
- Torbjørn Rognes and Erling Seeberg, [Six-fold speed-up of Smith–Waterman
  sequence database searches using parallel processing on common
  microprocessors](https://doi.org/10.1093/bioinformatics/16.8.699),
  Bioinformatics 16(8):699–706 (2000) — the query profile
- Jeff Daily, [Parasail: SIMD C library for global, semi-global, and local
  pairwise sequence alignments](https://doi.org/10.1186/s12859-016-0930-z),
  BMC Bioinformatics 17:81 (2016) — striped, scan, and diagonal layouts
  compared for global alignment
- Guy E. Blelloch, [Prefix Sums and Their
  Applications](https://www.cs.cmu.edu/~guyb/papers/Ble93.pdf) (1993) — the
  prefix maximum across lanes
- [Intel Intrinsics
  Guide](https://www.intel.com/content/www/us/en/docs/intrinsics-guide/index.html)
  — `_mm256_adds_epi16`, `_mm256_alignr_epi8`, `_mm256_permute2x128_si256`
