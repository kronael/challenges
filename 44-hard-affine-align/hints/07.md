# Hint 7

**Two layouts break the chain.**

- *Anti-diagonals.* Cell `(i, j)` reads only cells on the anti-diagonals
  `i + j - 1` and `i + j - 2`, so the cells of one anti-diagonal are
  independent and fill a vector. The price is the substitution score: along an
  anti-diagonal `s` runs forward while `t` runs backward, so every lane needs
  its own pair of residues looked up.
- *Stripes.* Walk `t` one column at a time and cut `s` into 16 strips of
  `seg = ⌈|s|/16⌉` rows. Vector `k` holds row `k` of every strip: rows `k`,
  `seg + k`, `2·seg + k`, … The row above any row is then the same lane one
  vector back. `Y`, the gap along `t`, passes from column to column in the
  outer loop; `X`, the gap along `s`, passes from vector to vector in the inner
  loop, sixteen strips at once. After one pass only the top row of each strip
  is short: its `X` should also see the bottom of the strip before it.

Stripes keep the substitution scores one load per vector. Before the first
column, write down for each of the 20 amino acids its score against every row
of `s`, in the striped order: a *query profile*. Each column then reads the
profile of its residue of `t`, one vector per `k`.

Sixteen 16-bit lanes are enough. For `|s|, |t| ≤ 2500` every score stays within
±27500, and saturating adds and subtracts keep a minus-infinity sentinel from
wrapping around.
