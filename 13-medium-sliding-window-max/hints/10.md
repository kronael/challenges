# Sources

- [Minimum stack / Minimum queue](https://cp-algorithms.com/data_structures/stack_queue_modification.html),
  CP-Algorithms — the monotone queue behind hints 1–3, and its use for the
  minimum of every subarray of fixed length.
- Marcel van Herk, "A fast algorithm for local minimum and maximum filters on
  rectangular and octagonal kernels", Pattern Recognition Letters 13(7),
  517–521, 1992. [doi:10.1016/0167-8655(92)90069-C](https://doi.org/10.1016/0167-8655(92)90069-C)
  — the block decomposition of hint 6.
- J. Gil and M. Werman, "Computing 2-D min, median, and max filters", IEEE
  Transactions on Pattern Analysis and Machine Intelligence 15(5), 504–507,
  1993. [doi:10.1109/34.211471](https://doi.org/10.1109/34.211471) — the same
  filter, published a year later.
- W. Daniel Hillis and Guy L. Steele Jr., "Data parallel algorithms",
  Communications of the ACM 29(12), 1170–1183, 1986.
  [doi:10.1145/7902.7903](https://doi.org/10.1145/7902.7903) — the
  logarithmic-depth prefix scan that `rise` runs across eight lanes.
- [Intel Intrinsics Guide](https://www.intel.com/content/www/us/en/docs/intrinsics-guide/index.html)
  — `_mm256_alignr_epi8`, `_mm256_permutevar8x32_epi32`, `_mm256_max_epi32`,
  `_mm256_blendv_epi8`, `_mm256_min_epu32`.
- [GCC developer options — `-fopt-info`](https://gcc.gnu.org/onlinedocs/gcc/Developer-Options.html)
  — the vectorizer's report of each loop it did not vectorize, and why.
